## Context

Two language ecosystems need native task APIs without embedded runtimes.

## Decision

Build independent pure-Python and pure-TypeScript task runners with shared conventions and behavioral specifications.

## Consequences

Shared conformance fixtures are needed; cross-language graphs are not automatic.
